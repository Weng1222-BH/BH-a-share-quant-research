# Stage 0 / Substage 0.1 / Session 1 学习记录

## 本节目标

- 从关注“策略是否赚钱”转向判断“支持策略的证据是否可信”。
- 建立样本内、样本外、随机噪声与过拟合的基本认识。

## 关键认知

- 历史高收益不等于策略可信。
- 样本内与样本外的关键在于数据是否参与策略设计、选择或调参。
- 测试数据一旦用于修改策略，就不再是干净的独立测试证据。
- 信号可能与随机噪声混合，反复选择和调参可能造成过拟合。
- 即使市场机制不变，新的随机扰动也可能使历史高收益无法重复。
- 单次样本外结果仍有随机性，不能据一次好坏直接判定策略有效或失效。
- 评估研究结果时，需要审查策略选择过程、参数修改、失败实验和停止条件，不能只看最终收益。

## 即时检查表现

- 能解释样本内与样本外的区别，以及测试数据被用于修改策略后为何会污染独立证据。
- 能解释机制不变时随机扰动仍会造成结果变化。
- 能识别单次样本外结果的局限，没有把一次好坏结果当作最终结论。

## 主要修正点

- 从“历史收益高，所以策略可信”修正为“收益表现必须结合证据产生过程审查”。
- 从按时间标签机械区分样本内外，修正为关注数据是否参与设计、选择或调参。
- 从只看最终入选策略，修正为同时关注参数修改、失败实验与停止条件。

## 当前掌握情况

- 已形成关于证据可信度、样本内外、测试污染、信号/噪声/过拟合和单次样本外随机性的基础解释能力。
- 待加强专业术语准确性，以及系统化审查量化策略的框架。
- 本节完成不代表已通过 Substage Gate。
